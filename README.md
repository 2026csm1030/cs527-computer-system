# CS527 Lab Assignment

Mini-Computer Simulation & Compiler   

## Summary

This assignment implements a functional **4-byte Instruction Set Computer (ISA)** simulation in C. It consists of a complete software pipeline:
1. **Compiler (`compiler.c`):** Translates high-level assembly-like instructions from `input.txt` into 4-byte machine code written to `program.byte`.
2. **Main Memory (`memory.c`):** Manages a 256-word RAM initialized from `data.byte`, handling dynamic `Read` and `Write` requests.
3. **Processor Core (`processor.c`):** Implements an Instruction Fetch-Decode-Execute pipeline operating on 256 general-purpose 32-bit registers.


## Instruction Set Architecture (ISA)

Each compiled instruction in `program.byte` is encoded as a fixed-width 4-byte string: `<opcode> <dest> <op1> <op2>`.

| Opcode | Operation | Assembly Format | Functional Description |
| :---: | :--- | :--- | :--- |
| `0` | **HALT** | N/A | Terminate execution pipeline |
| `1` | **ADD** | `xDest = xOp1 + xOp2` | Register addition |
| `2` | **SUB** | `xDest = xOp1 - xOp2` | Register subtraction |
| `3` | **MUL** | `xDest = xOp1 * xOp2` | Register multiplication |
| `4` | **DIV** | `xDest = xOp1 / xOp2` | Register division |
| `5` | **READ** | `Read xDest, Addr` | Load 32-bit value from Memory `Addr` into Register `xDest` |
| `6` | **WRITE** | `Write xSrc, Addr` | Store 32-bit value from Register `xSrc` into Memory `Addr` |
| `7` | **LOADI** | `xDest = Immediate` | Load immediate constant into Register `xDest` |

## Compilation & Build Instructions

This assignment requires GCC and standard GNU Make.

Clean Build Artifacts

To remove object files (.o), compiled binaries, and output files:

```Bash
make clean
```

## Running Test Suites

Automated test targets are built into the Makefile to quickly swap test programs and verify memory updates:

### Test Case 1: Add Four Variables

Summation of 4 variables.

```Bash
make test-sum
```

### Test Case 2: Complex Number Multiplication

Multiplies $(3 + 2i) \times (1 + 4i) = -5 + 14i$.

```Bash
make test-complex
```

Expected Result: Address 16 $\rightarrow$ -5 (Real Part), Address 20 $\rightarrow$ 14 (Imaginary Part).

### Test Case 3: $3 \times 3$ Matrix Determinant

Computes the determinant of matrix $A = \begin{pmatrix} 2 & 1 & 3 \\ 0 & 4 & 1 \\ 5 & 2 & 6 \end{pmatrix}$.

```Bash
make test-matrix
```

Expected Result: Address 36 $\rightarrow$ -11 ($\det(A)$).

## Output Verification

After executing any test, you can inspect the binary instructions generated by the compiler and the final state of memory:

```Bash
# View compiled 4-byte instructions
cat program.byte

# View updated RAM memory state
cat data.byte
```
